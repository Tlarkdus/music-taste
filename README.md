# 음악 취향 유형 테스트

**[테스트 해보기 →](https://tlarkdus.github.io/music-taste/)**

두 곡 중 끌리는 쪽을 12번 고르면 음악 취향 유형과 취향 지도, 닮은 아티스트, 추천 플레이리스트를 보여줍니다.

유형은 미리 정해두지 않고 데이터에서 뽑았습니다. 곡마다 Last.fm 태그를 모아 임베딩하고 군집으로 나눈 뒤, 그 축을 기준으로 질문을 만들었습니다.

## 파이프라인

| 단계 | 파일 | 하는 일 |
|---|---|---|
| 수집 | `collect.py` | Last.fm 태그별 인기곡과 아티스트 태그 수집 (이어받기 가능) |
| 한국 곡 보강 | `chart.py`, `bsides.py` | 가온·써클 디지털 차트 1위곡(2010~2025), 아티스트별 수록곡 |
| 보강 | `enrich.py` | Last.fm 청취자 수, iTunes 발매일·30초 미리듣기 |
| 임베딩 | `embed.py` | 태그 TF-IDF → SVD 32차원 → KMeans 12개 구역 |
| 내보내기 | `export.py` | 구역별 상한을 두고 곡을 골라 `web/data.js` 생성 |
| 화면 | `web/index.html` | 서버 없는 정적 페이지 |

취향 축은 네 개입니다. 잔잔/신남, 디깅/대중, 올드/최신은 곡 대결로 재고, 깊게/넓게는 양자택일로는 잴 수 없어서(시뮬레이션으로 확인) 마지막에 장르별 곡 중 끌리는 곡을 모두 고르게 했습니다.

## 다시 만들기

`config.py`에 `LASTFM_API_KEY`를 넣고 위 순서대로 `py` 로 실행합니다. 수집 데이터(`data/`)는 저장소에 넣지 않았습니다.
